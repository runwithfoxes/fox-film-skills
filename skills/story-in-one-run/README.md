# A story in one run

A whole story with your character, up to 30 seconds, in one run of Seedance 2.5, so the face holds all the way.

[SKILL.md](SKILL.md) has how to write the prompt as a shot list with seconds, the three things worth writing in, and
what to check. `example-canyon-prompt.txt` is the full prompt for our canyon film, and `story_run.py` runs a prompt
with your reference pictures on Replicate, reading your key from `REPLICATE_API_TOKEN`.

The film it made: runwithfoxes.com/craft/a-30-second-film-in-one-run
