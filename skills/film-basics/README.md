# Film basics

The base every film skill in this repo stands on. Read it first.

[SKILL.md](SKILL.md) covers what you need, the prices, and the list of things video models get wrong with a recurring
character and the words that stop each one. [your-character.md](your-character.md) shows how to make your own
character: one fixed description and one reference picture, used the same way every time.

`seedance_clip.py` makes a clip with Seedance 2 and `seedream_still.py` makes a still with Seedream 4.5, both on
Replicate, with your key read from `REPLICATE_API_TOKEN`. Both log what they spend.

Seedance 2 and Seedream are ByteDance's models. A 480p test clip costs about 40 cents for 5 seconds.
